Rule assessment

Review recommended

The default rule matches five failures within five minutes. A later success adds context; it does not prove compromise.

5Peak failures in window
YesSuccess after alert

What would I check next?

Review MFA results, device and sign-in context, and whether the account owner recognizes the activity.

Rule: same account + source IP · rolling time windowCorrelation: success within 10 minutes of an alert

Read the detection method and its limits

Method. Sort events by time. For each account and source IP, count failed logins within an inclusive rolling window. Flag that pair when it meets the selected threshold. Look for a successful login from the same pair within the next 10 minutes. Highlight contributing failures and correlated successes.

Limits. A matched rule is a prompt to investigate. Shared IPs, user mistakes, incomplete logs, and activity spread across accounts or addresses can change the interpretation. This small demo does not detect every attack or connect to a live system. Its example IPs are reserved for documentation.
