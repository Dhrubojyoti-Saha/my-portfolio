# Dhrubojyoti Saha — Cybersecurity Portfolio

A zero-build, recruiter-focused cybersecurity portfolio designed for GitHub Pages.

## Run it

No terminal, package manager, or build command is required. Open `index.html` directly in any modern browser.

## Folder structure

```text
.
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── script.js
├── assets/
│   ├── favicon.svg
│   └── og.png
├── .nojekyll
└── robots.txt
```

## Deploy with GitHub Pages

1. Create a public GitHub repository, for example `cybersecurity-portfolio`.
2. Upload every file and folder from this directory to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main**, folder **/(root)**, then save.
6. GitHub will provide a URL such as `https://USERNAME.github.io/cybersecurity-portfolio/`.

## Final content pass

Placeholder résumé, email, LinkedIn, GitHub, project, certificate, and report links show a clear reserved-link notice. Replace those links after the verified URLs are available.

The terminal is a safe visual interface that displays portfolio information only. It does not execute shell commands or access a visitor's system.
